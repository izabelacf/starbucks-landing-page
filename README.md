# ☕ Starbucks Landing Page

Landing page responsiva inspirada na Starbucks, desenvolvida como projeto de estudo para praticar **HTML, CSS e JavaScript**.

O projeto foi feito acompanhando um tutorial da **Larissa Kich** no YouTube.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo

Praticar conceitos de desenvolvimento Front-end, responsividade, organização de código e manipulação do DOM.

> Este projeto não possui vínculo oficial com a Starbucks.
